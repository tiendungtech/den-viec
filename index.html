    Lưu trữ trên GitHub

    Đang lưu vào file data.json trong repo .

    Việc của bạn sẽ được lưu vào file data.json trong một repo Private trên GitHub, nên mở trên máy nào cũng còn. Mỗi máy chỉ cần dán token một lần.

    1. Tạo một repo Private tên den-viec-data, nhớ tick Add a README file.
    2. Mở trang tạo token của GitHub. Mục Repository access chọn Only select repositories rồi chọn den-viec-data. Mục Permissions, thêm Contents và chọn Read and write. Chọn thời hạn, rồi bấm Generate token.
    3. Sao chép token và dán vào ô bên dưới.

    Token chỉ được lưu trên trình duyệt của máy này và chỉ được gửi tới GitHub.
